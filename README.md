# The Samriddhi Era ✨ (Taylor's Version)

> *"I was enchanted to meet you... Please don't be in love with someone else."*

An aesthetic, mobile-responsive confession website crafted with love for **Samriddhi (Gullu)** — inspired by Taylor Swift aesthetics, warm cafe romance, and cherished memories.

---

## ✨ Key Features

- **☕ Warm Cafe & Holographic Aesthetic:** Curated rose-gold, deep violet, and espresso palette with subtle floating fairy dust particles.
- **📸 43-Photo Memory Gallery:** Interactive masonry grid and swipeable polaroids with custom Taylor Swift lyrics tagged on every photo.
- **🎵 Taylor Swift Vinyl Jukebox:** Integrated audio streaming featuring:
  - *Enchanted (Taylor's Version)*
  - *Lover*
  - *Love Story (Taylor's Version)*
  - *You Belong With Me (Taylor's Version)*
  - Expandable **📺 Live Lyric Video Screen** & custom MP3 player support.
- **💌 3D Wax-Sealed Confession Letter:** Interactive envelope with a wax stamp ("G") that breaks open with sound to reveal the personal confession letter.
- **📲 1-Tap WhatsApp Response:** When she taps her answer, it triggers a confetti celebration and prepares a direct 1-tap WhatsApp message to send her reply instantly!
- **⚡ Live Response Tracker:** Built-in real-time response tracker dashboard (`responses.html`).

---

## 🚀 Running Locally

1. Start the local server:
   ```bash
   node server.js
   ```
2. Open in browser:
   - PC: `http://localhost:5173`
   - Mobile: `http://<your-local-ip>:5173`
   - Live Tracker: `http://localhost:5173/responses.html`
